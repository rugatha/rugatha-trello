# 階段五：個人主題與介面驗證

2026-10-10 完成階段五的本機開發與測試；四項清單在各自驗證通過後即時勾選。尚未部署前端與新版 Firestore 規則，正式站驗證留在階段六。

## 個人主題

帳號視窗提供「明亮／深色」設定，只在既有 `workspaces/main/members/{memberId}` 文件寫入 `theme`。不建立另一份會員、UID 或信箱資料；同一會員的不同 Google 信箱共用偏好。缺少或無效偏好使用明亮介面；登出、撤權與切換帳號時重設。個人主題調整閱讀表面，五種共用看板背景仍依看板 `color` 呈現。

Firestore 規則僅允許已核准會員變更自己的 `name`／`theme`，主題限 `light`、`dark`，不能一起改寫角色、信箱或看板授權。偏好透過既有會員訂閱更新；只有主題變更時，不重讀看板或關閉編輯中的視窗。等待伺服器成功才套用新選擇；失敗保留已儲存偏好、錯誤與重試能力。舊帳號延遲完成／失敗不更新新帳號畫面。

## 色彩與操作提示

色彩集中於 `style.css` 的預設變數與深色覆寫；看板與欄位色點使用五種受控預設色。標籤僅使用既有五種色盤，未知色值回退為紫色，不改寫雲端資料。修正計數文字對比：原先約 4.17:1，現在約 5.00:1。

會員名冊僅供閱讀，不提供本機切換身分；牌卡指派勾選僅顯示現況，透過 Owner／Admin 的管理流程修改。未登入、未核准、無看板、唯讀、載入及儲存狀態提供一致提示。Viewer／一般會員仍可開啟牌卡、讀取及下載附件；不啟用寫入與拖曳。

## 手機與無障礙

修正頂列換行、側欄導覽可讀寬度、窄畫面的篩選與狀態列、牌卡詳情及帳號對話框溢位。提供跳到看板內容連結、可聚焦的水平捲動區、對話框名稱、表單標籤、篩選／收藏狀態、可見焦點與減少動態效果支援。卡片儲存使來源 DOM 重建後，關閉詳情仍將焦點返回原卡片。

## 驗證與重跑

- `npm test`：100 項應用回歸通過，包含新主題的偏好保存、失敗、撤權與帳號競態。
- `PATH=/opt/homebrew/opt/node@24/bin:/opt/homebrew/opt/openjdk@21/bin:$PATH npm run test:rules`：35 項 Firestore 模擬器規則測試通過，包含五角色、同會員另一信箱、非預設值、越權、未核准／停用／匿名拒絕。
- Firefox：104 項介面檢查通過，分為個人主題 12 項、色彩對比 30 項、會員與權限 26 項、手機與無障礙 36 項。
- 對比以 Firefox 計算樣式檢查明暗主題的牌卡文字、說明、計數、五種標籤、主要按鈕、表單說明與五種看板配色；受測文字皆至少 4.5:1。
- 排版檢查涵蓋 320、375、600、850、1100px iframe 視窗；另人工檢視 375px 看板。以實際 Enter、Tab、Escape 驗證詳情開啟、焦點移動與關閉後返回牌卡，並檢查 Firefox 無障礙樹的欄位名稱及狀態。

重跑 Firefox：執行 `python3 scripts/serve-phase5-test.py`，以 Firefox 開啟 `http://127.0.0.1:8005/tests/browser/phase5.html`，依序點擊四個測試按鈕。伺服器由目前的 `index.html` 產生測試頁，載入真實 `auth.js`、`app.js`、`membership-ui.js` 與 `style.css`；Firebase、管理端點、看板及附件呼叫都透過 import map 導向記憶體替身，不連接正式 Firebase。測試資料與寫入僅存於該測試頁記憶體。

這些檢查不等同實機手機、VoiceOver 語音播報或正式站驗證；尚未進行新版部署、正式 Firebase 偏好存取及跨瀏覽器實際登入驗證。這些工作留待階段六。
