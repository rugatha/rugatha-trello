2026-10-11，來源為 `rugatha-trello` 正式 Firestore 的 `workspaces/main/members` 與 `boards`。私人 CSV 和匯出時的版本快照保存在被 Git 忽略的 `import/`，不放入網站或 Git。

## 如何調整

開啟 `import/user-board-permissions-2026-10-11.csv`：每位會員一列，前五欄是會員 ID、姓名、電子郵件、角色及狀態，後七欄是看板授權。

- `1`：授予該看板權限；`0`：不授權。請只調整看板欄的 `1`／`0`，保留標頭、會員 ID 及前五欄。
- 看板欄包含名稱和穩定 ID；兩個已封存看板在標頭註記「已封存」。授權不會解除封存，也不會改變角色。
- Viewer 只能檢視，Editor 可編輯未封存看板。CSV 的數字對應儲存的看板授權；實際登入仍要求有效會員及已連結信箱。于哲目前 `unlinked`，沒有信箱或看板授權。
- 雨嶸與 Jim 都是 Editor，目前有五個未封存看板的權限。
- 儲存為 UTF-8 CSV，交回調整後檔案再套用。匯出本身沒有改變任何看板權限。

CSV 已用 Artifact Tool 建立及重新讀取核對，包含 14 位會員、7 個看板、77 項授權。採 UTF-8 BOM 及標準 CSV 引號，支援 Excel／Numbers 的中文和多信箱欄位。

後續套用時，以 `member_id` 和看板 ID 配對；先核對匯出快照與最新會員版本，拒絕未知或重複 ID、缺列、非 0／1 值及未經要求的角色／身分修改。只更新有調整的看板授權並備份修改前資料，使用版本條件避免覆蓋同時發生的管理變更。
