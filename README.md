# 板塊 Boardly

以 Trello 風格製作的繁體中文專案管理頁面，無須安裝套件。請透過本機 HTTP 伺服器開啟，以便載入獨立的 JSON 資料檔。

## 檔案分工

- `index.html`：頁面結構與對話框容器。
- `style.css`：版面、品牌配色、響應式樣式。
- `app.js`：卡片、看板、成員、拖曳與篩選等互動，以及啟動流程。
- `storage.js`：IndexedDB 儲存與初始 JSON 載入。
- `data.json`：預設成員與已轉換的 Trello 看板資料。

`data.json` 用於首次初始化，以及版本化的成員／Trello 資料合併。操作後的內容仍存入 IndexedDB，不會直接寫回專案內的 JSON。修改初始資料不會覆蓋現有工作；若要套用到既有工作空間，可先匯出備份，再使用匯入功能選擇 `data.json`。

## 啟動

在專案目錄執行：

```sh
python3 -m http.server 8000
```

開啟 `http://localhost:8000`。請不要直接雙擊 HTML，瀏覽器可能阻止 `file://` 讀取 JSON。固定使用同一個網址與連接埠以沿用資料；如果原先透過 `file://` 使用，請先從舊頁面匯出備份，再於新網址匯入。

## 使用方式

1. 初次進入時選擇成員，或輸入自己的 username。
2. 在左側切換專案看板；按「我的看板」旁的 ＋ 新增看板。
3. 按「新增階段」自訂工作流程；階段旁的 ⋯ 可改名、調整順序或刪除空階段。
4. 新增卡片後，點開卡片編輯說明、負責人、截止日期、完成標記、標籤與待辦事項。
5. 拖曳卡片即可跨階段移動或排序；手機可使用卡片內的「所在階段」選單。
6. 附件每個上限 15 MB，可下載；支援的圖片格式可指定為卡片封面。
7. 留言保留發言時的 username 與時間戳，右上角可切換身分。
8. 可依標題／說明搜尋、篩選指派給自己、已逾期或未來七天的任務。
9. 左下角可匯出含附件的 JSON 備份；匯入會在確認後取代現有資料。

## 資料保存與範圍

- 所有看板及附件保存在此瀏覽器的 IndexedDB；目前身分保存在分頁的 sessionStorage。
- 這是單機 HTML 應用，不含後端、帳號認證、權限控管或跨裝置即時協作。不同 user 是本機可切換的工作身分。
- 清除網站資料、使用無痕視窗或更換瀏覽器／網址可能造成資料無法沿用，請定期匯出備份。
- 截止日期依使用者的本地時間判斷；留言時間以 ISO 時間戳保存並以本地時間顯示。完成狀態獨立於自訂階段名稱，請勾選「已完成任務」以停止逾期提示。
- 首次開啟會載入已轉換的 Trello 看板。

## 使用者頭像簡稱

編輯 `data.json` → `users` 中的 `shortName` 即可調整圓形頭像文字，例如：

```json
{ "id": "member-01", "name": "DM 威辰", "shortName": "威" }
```

預設填入名稱的第一個字元，建議簡稱使用 1–2 個字元。保留原本的 `id`、`name` 和其他欄位，只修改 `shortName`。儲存後重新整理頁面即可同步至既有瀏覽器資料，不需重新匯入，也不會覆蓋看板或留言。留空時回退到名稱的第一個字元。GitHub Pages 須等待更新部署完成後再重新整理。
